# Сумма отрицательных элементов между максимумом и минимумом

Учебный проект по учебной практике (ознакомительной практике), направление
10.03.01 «Информационная безопасность», профиль «Белый хакер».

## Задача

Дан одномерный массив `A` размерности `N`. Требуется найти сумму отрицательных
элементов, расположенных между максимальным и минимальным элементами массива.

Договорённости:

- рассматриваются элементы, расположенные **строго между** максимумом и
  минимумом, сами экстремумы в сумму не входят;
- если максимум или минимум встречается несколько раз, используется **первое**
  вхождение;
- если между экстремумами нет элементов или среди них нет отрицательных,
  результат равен `0`;
- для массива из одного элемента результат также равен `0`.

## Алгоритм

1. Запомнить индекс первого максимума и индекс первого минимума.
2. Определить левую и правую границы промежутка: `left = min(max_i, min_i)`,
   `right = max(max_i, min_i)`.
3. Пройти по элементам `A[left + 1 ... right - 1]` и сложить только
   отрицательные значения.
4. Вывести исходный массив, индексы и значения экстремумов, элементы между
   ними и итоговую сумму.

Временная сложность — `O(N)`, дополнительная память — `O(1)` (не считая самого
массива).

## Запуск

Требуется Python 3.8 или новее. Сторонние библиотеки не используются.

```bash
python main.py
```

Пример ввода:

```text
10
5 -3 -7 2 8 -1 4 -9 6 0
```

Пример вывода:

```text
Поиск суммы отрицательных элементов между максимумом и минимумом
Введите количество элементов N: 10
Введите 10 целых чисел (можно в одной строке через пробел или по одному):
5 -3 -7 2 8 -1 4 -9 6 0

Исходный массив: [5, -3, -7, 2, 8, -1, 4, -9, 6, 0]
Максимум: a[4] = 8
Минимум:  a[7] = -9
Элементы между ними: [-1, 4]
Сумма отрицательных элементов: -1
```

Максимум `8` находится в позиции `4`, минимум `-9` — в позиции `7`. Между ними
расположены элементы `-1` и `4`; единственный отрицательный элемент `-1`
образует искомую сумму.

## Тесты

В проекте 10 модульных тестов: обычный пример, массив без отрицательных чисел,
массив только из отрицательных чисел, одинаковые элементы, соседние экстремумы,
повторяющиеся максимум и минимум, один элемент, пустой массив.

```bash
python -m unittest discover -s tests -t . -v
```

```text

```
