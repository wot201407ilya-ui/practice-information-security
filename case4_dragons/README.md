# Максимальная сила драконьей стаи

Учебный проект по учебной практике (ознакомительной практике), направление
10.03.01 «Информационная безопасность», профиль «Белый хакер». Кейс-задача № 4.

## Задача

Известно, что у дракона может быть несколько голов, а сила дракона
определяется числом голов. Сила стаи равна произведению чисел голов всех
драконов. Например, для драконов с 3, 4 и 5 головами сила равна
`3 * 4 * 5 = 60`.

Требуется по суммарному числу голов `N` найти максимально возможную силу стаи.
У одного дракона не может быть больше 7 голов.

Вход: натуральное число `N`, `0 < N < 100`.
Выход: максимально возможное значение силы.

## Математическая модель

Нужно выбрать целые числа `x1, x2, ..., xk` так, чтобы:

- `x1 + x2 + ... + xk = N`;
- `1 <= xi <= 7` для каждого дракона;
- произведение `x1 * x2 * ... * xk` было максимальным.

Число драконов `k` заранее не задано и определяется в ходе решения.

Пример `3 * 4 * 5 = 60` из условия показывает, как считается сила, но не
является максимальной силой для `N = 12`: оптимальное разбиение для 12 голов —
`3 + 3 + 3 + 3`, сила `81`.

## Алгоритм динамического программирования

Пусть `dp[s]` — максимальная сила, которую можно получить из `s` голов.
База: `dp[0] = 1` (пустое произведение). Для каждого `s` от 1 до `N`
перебираются все возможные размеры последнего дракона `k` от 1 до 7:

```text
dp[s] = max(dp[s - k] * k),  1 <= k <= min(7, s)
```

Дополнительный массив `choice[s]` запоминает, при каком `k` достигнут
максимум. После заполнения таблицы разбиение восстанавливается от `N` к нулю:
берём `choice[remaining]`, добавляем дракона с таким числом голов и уменьшаем
остаток.

Сложность: `O(7N) = O(N)` по времени и `O(N)` по памяти. При `N < 100` это
несколько сотен операций.

## Запуск

Требуется Python 3.8 или новее. Сторонние библиотеки не используются.

```bash
python main.py
```

Пример ввода:

```text
12
```

Пример вывода:

```text
Максимальная сила драконьей стаи
Введите количество голов N (1..99): 12

Количество голов: 12
Максимальная сила стаи: 81
Количество драконов: 4
Оптимальное разбиение: 3 + 3 + 3 + 3 = 12
Проверка произведения: 3 * 3 * 3 * 3 = 81
```

## Тесты

В проекте шесть тестов:

- известные значения для `N` от 1 до 13, а также для 20, 30, 50 и 99;
- проверка корректности разбиения для всех `N` от 1 до 99: сумма частей равна
  `N`, каждая часть от 1 до 7, произведение совпадает с результатом;
- проверка ошибок для `N = 0`, отрицательных значений и `N >= 100`;
- проверка жадного алгоритма: совпадение с ДП для всех `N` от 1 до 99,
  корректность разбиения и обработка ошибок.

```bash
python -m unittest discover -s tests -t . -v
```

Ожидаемый результат:

```text
Ran 6 tests in 0.013s

OK
```

## Дополнительно: жадный алгоритм

В файле `greedy.py` реализован жадный алгоритм, предложенный в кейс-задаче № 5.
Он использует оптимальные части 3, 2 и 4:

- остаток 0 — все тройки;
- остаток 1 — одна четвёрка и тройки;
- остаток 2 — одна двойка и тройки.

Тест `tests/test_greedy.py` сравнивает жадный алгоритм с динамическим
программированием для всех `N` от 1 до 99; расхождений нет.
